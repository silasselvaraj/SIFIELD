# SIFIELD

Image + Motion Studio

SIFIELD is a browser-based creative studio for transforming images, video, and sound into geometric artwork and expressive motion graphics. The goal is to combine contour-driven geometry, layered visual effects, intelligent subject protection, and audio-reactive animation in an approachable workspace with local media processing.

## Product vision

- Create contour lines, geometric symbols, connection graphs, grids, and circle chains from source imagery.
- Layer dithering, grain, scanlines, color extrusion, pixel memory, palettes, and blend modes.
- Animate artwork using reproducible seeds, motion controls, and music-driven effects.
- Protect or emphasize subjects with face and object analysis.
- Export high-quality still images and social-ready video.

## Current status

The foundation includes a responsive English editor, local image/video loading, preview, edge inspection, playback hold, undo/redo, randomized settings, JSON settings save/load, and source PNG download. Artistic effect controls currently store settings. Effect rendering, audio analysis, subject detection, and encoded video export are planned.

## Run locally

Open `index.html` in a modern browser. No dependency installation or build step is required.

## Roadmap

3. Motion, audio reactivity, subject detection, and export pipelines.
